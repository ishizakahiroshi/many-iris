# Many Iris — local foundation candidate

自分の案件を見渡し、計画を指定してAIへ任せるための、個人用OSSの実装候補です。まず作者自身が使いやすい道具に仕上げ、環境と使い方が合う人に公開する方針です。一般向けの設定不要サービスや、全ベンダーへの対応を約束するものではありません。

**この候補は合成データ・架空の担当だけで動きます。実AI、実案件、スマホPushには接続しません。** 製品初版の完成や長時間の実AI稼働を示すものではありません。Desklyのデータ移行や全機能の置き換えは行いません。

## 起動

Python 3.11以上が必要です。追加パッケージのインストールやビルドは不要です。

```powershell
python -B -m prototype.server
```

最初の出力に `http://127.0.0.1:<port>` のURLが出ます。同じPCのブラウザで開いてください。止めるときは実行した端末でCtrl+Cを押します。既定の状態保存先は `.state/foundation.sqlite3`、ポートは毎回空いている番号を選びます。公開ネットワークへは待ち受けません。同じDBで二つのサーバーは起動できません。

新しい合成の試行を残す場合は、既存ファイルを削除せず別のDB名を指定します。

```powershell
python -B -m prototype.server --db .state/second-trial.sqlite3
```

## 試せる流れ

1. 架空の計画を選び「この計画を開始」を押す。
2. 最初の作業が自動で完了し、判断が必要な作業で待つ。
3. 根拠の原文と指示の版を確認する。
4. 「合成の停止・引き継ぎを試す」で架空担当の停止を確認すると、自動で別の担当へ引き継ぐ。必要な承認は新担当用に作り直す。
5. 承認すると残りの作業が自動で完了する。却下するとその計画は進まない。

別の計画は、明示的に開始しない限り実行されません。片方が承認待ちでも、別途開始した独立計画は進められます。停止確認ボタンは実AIへの停止命令ではありません。

## 守っている境界

状態・要求の応答・経過・通知候補はSQLiteへ一つのトランザクションで保存します。同じ要求IDと内容の再受信は同じ応答を返し、内容の変更は拒否します。同じ計画の二重開始も拒否します。承認は計画・作業・run・担当世代と版に結び付き、古い承認や旧担当の結果を採用しません。

再起動時に実行途中の結果が確定できなければ「結果不明」で止め、勝手に再送しません。完了済み・却下済み計画の再実行は未対応です。実行途中を含む結果不明からの手動照合と復帰は、今後の実装事項です。

HTTPは正しいローカルHost/Origin・要求形式・サイズを検査します。ローカルで同じユーザー権限を持つプログラムを防ぐ認証やOSのsandboxではありません。外部公開やトンネル経由のスマホ接続に使わないでください。

## 接続準備の確認

```powershell
python -B -m prototype.doctor --config examples/adapter.json
```

添付例は未設定なので `configured:false`、終了コード2を返します。設定済みと見せかけません。明示したローカル実行ファイルの絶対パス等を検査することはできますが、この検査はプログラムを起動せず、認証設定や秘密情報を自動取得しません。実ベンダーの接続検査でもありません。

`prototype.adapter.LocalProcessAdapter` は固定した実行ファイルへJSONを渡す、初期状態無効の通信候補です。試験では短い架空のPython担当だけを起動しています。実行期限・出力量・結果の対象/版/担当世代を検査し、失敗は結果不明として再試行しません。自律schedulerには接続していません。子孫プロセスの封じ込めやOS sandboxは実装していないため、任意の実ベンダーCLIを無人で起動できる完成品ではありません。環境変数を限定しても、同一ユーザーの実行ファイルによるファイル読取まで防ぐものではありません。

## 通知の準備

```powershell
python -B -m prototype.notifications --db .state/foundation.sqlite3
```

判断待ち・人の対応が必要・完了の通知候補を、汎用文言でローカルに表示します。案件名・本文・原文・資格を配送用の文言へ含めません。外部送信は無効で、スマホへの購読設定・実到達は未確認です。通知を見なかったことを、承認や作業成功として扱いません。

## 検証

```powershell
python -B -m unittest discover -s tests -v
```

実行制御・保存・再起動・承認・交代・遅延結果・HTTP境界・設定検査・通信上限・通知最小化の対象試験があります。実HTTPと実行核・schedulerをつなぐ試験も含みます。PCとスマホ相当幅のブラウザ確認は、実スマホ受入とは別です。

## 公開までに残ること

実案件の取得元と非中継経路、実行可能なAI adapter、権限と本人確認、実スマホ・Push到達、本人の実用受入を確認する必要があります。接続先の仕様変更・提供終了で該当機能が使えなくなる場合があります。利用者自身による認証・設定・疎通確認を前提に、確認した環境と手順を示す方針です。
