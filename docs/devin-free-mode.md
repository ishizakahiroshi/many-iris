# Devin Free mode（クラウド無料枠）の調査記録

Devin のクラウドに、SWE-2 を使った無料枠「Free mode」が追加されたという
調査の記録です。調査日は 2026-11-22 です。

## この記録の位置づけ

- このファイルは調査記録のみで、コードの変更はありません。
- 書いているのは、2026-11-22 時点で確認できたことだけです。
- さらに詳細な調査は別途 ChatGPT に頼む予定です。そのため、未確認の
  ことを断定しない書き方にしています。出典にない仕様は書いていません。
- many-iris の Issue #41 に関連する調査です。この記録だけでは #41 の
  完了条件は満たさないため、Issue は閉じません（PR 本文は `Refs #41`）。
- 秘密情報・鍵・個人データは含んでいません。

## 結論（今わかっていること）

- 2026-11-12 の Cognition の Teams プラン更新で、クラウドの
  「Free (powered by SWE-2)」、すなわち Free mode が追加されました。
- Free mode のセッションは、上限・クレジットを消費しません。
- 無料枠の同時セッション数は、Pro が 2、Max が 4、Teams がメンバー
  1 人あたり 2 と報告されています。ただし公式ドキュメントで明記
  されているのは Teams の 2 枠までで、Pro 2・Max 4 はアプリ画面
  確認ベースの報告です。詳しくは下記の「無料枠の同時セッション数」を
  見てください。
- 有料の同時セッション上限は別枠です。Pro / Max は最大 10、Teams は
  無制限です。
- エフォート（推論の深さ）について、Free mode で Max まで使えるとは
  断定できません。詳しくは下記の「エフォート」を参照してください。
- many-iris #41 の方針 6「ローカルが寝ているときだけ VPS 軽量バッチ／
  Devin へ」に関係します。Pro の無料 2 枠で、ローカル睡眠時の Devin
  フォールバックをまかなえる可能性があります。ただし無料枠は最大でも
  4 枠なので、ローカル 30 並列の代替にはなりません。ローカル並列の
  計画はそのまま必要です。

## 何が変わったか

2026-11-12（日本時間では 11-13）の Cognition の Teams プラン更新で、
次の変更が発表されました。

- Teams の全メンバーが Devin Desktop を追加のシート料金なしで使える
  ようになった。
- 新しい Free mode が追加され、各ユーザーが SWE-2 を使った無料の
  クラウドセッションを同時に 2 件まで実行できるようになった。
- 同時に、Devin Desktop と Devin CLI での SWE-2 の無料利用が、Teams、
  Pro、Max の各プランで恒久的なものになるとブログでは説明されています。

このうち、クラウドの Free mode については、公式ドキュメントの
self-serve plans のページ（2026-11-17 更新）でも、Teams プランの
説明として「Free mode: each member can run up to 2 cloud sessions at
a time at no cost」と記載されています。同ページの Free mode の節では、
Teams プランでは各メンバーがエージェント選択で「Free (powered by
SWE-2)」を選ぶことでクラウドセッションを無料で実行でき、同時に
最大 2 件まで、3 件目を始めるには 1 件が終わるのを待つか、別の
モードを選ぶこと、他のモードのセッションは通常どおり課金されること
が説明されています。

## 無料枠の同時セッション数

### 確認できた数

| プラン | 月額 | 無料枠（Free mode）の同時セッション数 |
| --- | --- | --- |
| Pro | $20/月 | 2 |
| Max | $200/月 | 4 |
| Teams | $80/月から | メンバー 1 人あたり 2 |

### 公式と画面確認の区別

この表の数は、確認のしかたがプランによって異なります。混ぜないで
ください。

- **Teams の 2 枠は、公式ドキュメントで明記されています。**
  self-serve plans のページ（2026-11-17 更新）の Teams の説明と
  Free mode の節に、メンバー 1 人あたり最大 2 件まで無料で実行できる
  と書かれています。
- **Pro の 2 枠と Max の 4 枠は、アプリ画面確認ベースの報告です。**
  公式ドキュメントには、2026-11-22 時点では Pro / Max の無料枠の数
  は明記されていません。
  - X の Kinopee 氏の投稿では、「Devin cloud も SWE-2 は上限を消費
    しません。ただし、プランごとの同時セッション数上限はあります
    （画面確認ベースで Pro 2、Max 4、Teams 2」と説明されています。
  - Devin Central の Chris Wozniczek 氏の 2026-11-16 の投稿でも、
    クラウドセッションの無料 SWE-2 について「Pro up to 2 concurrent
    cloud sessions, Max up to 4」と報告されています。
  - ユーザーのスクリーンショットにも、Max のものとみられる画面で
    「Free (powered by SWE-2)」「The plan includes 4 concurrent
    sessions」「0/4 in use」と表示されていました。

つまり、Pro 2・Max 4 という数は、画面で確認したという報告に基づく
もので、公式ドキュメントの記載に基づくものではありません。この記録
ではその区別を残しています。実際に使う前に、自分のアカウントの
アプリ画面で「Free (powered by SWE-2)」が表示されることと、同時
セッション数を確認してください。

## 有料の同時セッション上限は別枠

無料枠の数と、有料セッションの同時実行上限は別のものです。

- **有料の同時セッション上限：Pro / Max は最大 10、Teams は無制限**
  です。これは、料金ページの比較表などに基づく従来からの説明です。
- 無料枠は、その上に重なる「無料で使える分」です。たとえば Pro では、
  無料枠 2 件に加えて、有料モードでさらにセッションを実行できます。
  ただし有料モードの分は、上限・クレジットを消費します。

無料枠が 2〜4 件あるからといって、クラウドで何件でも無料で並列
実行できるわけではありません。

## 以前の前提との違い

many-iris の計画では、これまでクラウドの Devin は敬遠されていました。
その前提は、SWE-2 の無料利用はローカルの Devin CLI（と Devin
Desktop）だけ、というものでした。今回の調査で、その前提は次のように
変わりました。

- **従来のモデルドキュメントの説明：**「SWE-2 is free for self-serve
  plans in Devin Desktop and Devin CLI through November 30, 2026; it
  does not apply to Devin cloud sessions.」すなわち、SWE-2 の無料利用は
  Devin Desktop と Devin CLI のみで、2026-11-30 まで、クラウドの
  セッションには適用されない、とされていました。
- **2026-11-12 のブログの説明：** Devin Desktop と Devin CLI での
  SWE-2 の無料利用が、Teams、Pro、Max の各プランで恒久的なものに
  なるとされています。
- **矛盾は未解決です。** モデルドキュメント側は、2026-11-22 時点でも
  まだ「2026-11-30 まで」と書いており、ブログの「恒久化」の説明と
  食い違っています。この記録では、どちらか一方を正しいと断定しません。
  11-30 以降の Desktop / CLI での SWE-2 無料の扱いも、未確認です。

クラウドの Free mode は、この Desktop / CLI の無料利用とは別の枠
です。Free mode のセッションが無料であることは、Teams については
公式ドキュメントで確認できていますが、Free mode 自体の期限や恒久性
について、公式ドキュメントに明記された説明は 2026-11-22 時点では
確認できていません。

## エフォート（推論の深さ）

### SWE-2（有料セッション）は Medium / High / Max を選べる

SWE-2 は、Medium、High、Max の 3 段階の推論エフォート（reasoning
effort）を持つモデルです。公式ドキュメントのモデル一覧では、SWE-2
について「available in Medium, High, and Max reasoning effort」と
説明されています。Enterprise 向けの「Your First Session」のページでも、
エージェント選択の表で SWE-2（research preview）について「Pick a
reasoning effort of Medium, High, or Max」と説明されています。

### Free mode のエフォート上限は公式ドキュメントに明記されていない

Free mode については、エフォートがどこまで使えるかは、公式ドキュメント
に明記されていません。次の 2 点に注意してください。

- 公式のエージェント選択表では、「Free (powered by SWE-2)」は SWE-2
  とは別行のエージェントとして並んでいます。SWE-2 の行には Medium /
  High / Max を選べると書かれていますが、Free の行にはエフォートの
  記載がありません。Free mode を選んだら SWE-2 のエフォート選択肢が
  出る仕組みだとは、公式ドキュメントからは読み取れません。
- そのため、**Free mode で Max エフォートが使えると断定しません。**
  Max の推論が欲しい場合は、Free mode ではなく通常の SWE-2 セッション
  で Max を選ぶ形になります。その分は上限・クレジットを消費します。

### 前例：SWE-2 Flash は Free プランだと Medium のみ

前例として、SWE-2 Flash については、公式ドキュメントのモデル一覧に
「Free plans can select Medium; High and Max require a paid plan.」と
明記されています。すなわち、Free プランでは Medium のみ選べて、High
と Max には有料プランが必要です。無料枠でエフォートに制限が付く
ことは、Devin のこれまでの扱いにもある、ということです。ただし、
これは SWE-2 Flash の話であり、Free mode の SWE-2 のエフォートが
Medium に固定されていると断定する根拠にはなりません。Free mode の
エフォートが固定かどうか、固定だとしてどの段階かは、未確認です。

### 「Max プラン」と「エフォート Max」は別物

混同しやすいため、明記します。

- **Max プラン**は、月額 $200 のプラン名です。Pro より大きな週次
  の使用枠を持ち、日次の上限がありません。
- **エフォート Max**は、SWE-2 の推論の深さの段階名です。
  Medium / High / Max のうち最も深い段階です。

Max プランに入っているからといって、Free mode が Max エフォートに
なるわけではありません。Max プランで増えるのは、無料枠の数が 2 から
4 になること（画面確認ベースの報告）であって、Free mode のエフォート
が Max になることではありません。

## many-iris #41 との関係

many-iris の Issue #41「VPS 中継ハブ＋ローカル並列ハイブリッド運用の
実装」では、実装方針の 6 番目として「ローカルが寝ているときだけ
VPS 軽量バッチ／Devin へ」と決めています。

今回の調査結果は、その方針 6 に関係します。

- **ローカル睡眠時の Devin フォールバックを、Pro の無料 2 枠でまかな
  える可能性があります。** ローカルの PC が寝ている時間帯に、軽い
  仕事をクラウドの Free mode に預ける、という使い方が考えられます。
  その場合、無料枠の分は上限・クレジットを消費しません。
- **ただし、無料枠は最大でも 4 枠なので、ローカル 30 並列の代替には
  なりません。** #41 で計画している、ローカル PC での約 30 セッション
  の並列実行を、クラウドの無料枠に置き換えることはできません。
  ローカル並列の計画は、そのまま必要です。
- 有料枠を使えば Pro / Max でも最大 10 件まで同時に実行できますが、
  それでも 30 並列には届かず、かつ上限・クレジットを消費します。
  Teams なら同時セッション数は無制限ですが、料金体系が別であり、
  この記録では Teams への移行を提案していません。

この記録は調査のみで、#41 の設計（`docs/vps-relay-hub.md`、PR #42）
を変更するものではありません。方針 6 に Free mode をどう書き込むかは、
別途判断する事項です。
